# Memo Wiki

**Wikipedia のように、メモ同士をリンクでつなげられるメモ帳アプリです。**

「あの話、たしか別のメモに書いたな」を減らすために作りました。
書いた内容を線でつないでいくと、あとから知識のつながりが図で見えるようになります。

リンクを貼るのも画像を入れるのも、覚える記号や書き方はありません。
すべてボタンを押すだけ、貼り付けるだけでできます。

![編集画面](docs/images/screen-editor.png)

---

## できること

- **メモ同士をつなぐ** — 文字を選んでボタンを押すだけで、別のメモへのリンクになります
- **Webサイトのリンクを貼る** — 文字にURLを埋め込んだり、見出し画像つきのカードにしたり、YouTubeの動画をメモの中で再生したりできます
- **画像を入れる** — ファイルを選ぶ、コピーして貼り付ける、ドラッグして落とす、どの方法でも入ります
- **ページの見た目を整える** — ページの一番上に大きな画像を置けます。見出し・太字・箇条書きも使えます
- **目次をつける** — Wikipediaのような目次を入れられます。見出しから自動で作られ、クリックでその場所へ移動できます
- **つながりを図で見る** — どのメモがどれとつながっているか、地図のように一覧できます
- **探す** — タイトルからも本文からも検索できます
- **自動で保存** — 別のメモに移るときに自動で保存されるので、保存し忘れがありません
- **使い方をいつでも確認** — 左下の「?」ボタンから、アプリの中で使い方を読めます

## インストール

1. [Releases のページ](../../releases/latest) を開きます
2. `MemoWiki-Setup-○○○.exe` をクリックしてダウンロードします
3. ダウンロードしたファイルをダブルクリックします
4. 確認画面が出るので、内容を確かめて進めます（インストール先も選べます）

デスクトップとスタートメニューにアイコンができます。
なお、**確認画面が出るのは初回だけ**です。次回以降の更新は自動で行われます。

> **「WindowsによってPCが保護されました」と出たときは**
>
> 見慣れないアプリに出る注意画面です。
> **「詳細情報」** をクリックし、出てきた **「実行」** ボタンを押すと進めます。
> 2回目からは出ません。

対応しているのは Windows です。

## 使い方

> **使い方に迷ったら**
> 画面の**左下にある「?」ボタン**を押すと、この使い方がアプリの中でいつでも読めます。

### メモを書く

左上の **「+ 新規ページ」** で新しいメモを作ります。
上の欄にタイトル、その下に本文を書きます。
タイトルの下の細い欄には、一行の説明（サブタイトル）を書いておくと、
左の一覧に表示されて見分けやすくなります。

### メモ同士をつなぐ

1. つなげたい文字をドラッグして選びます
2. 上の **「🔗 リンク」** を押します
3. 出てきた一覧から、つなげたいメモをクリックします

まだ無いメモにつなぎたいときは、
**「「〇〇」で新しいページを作ってリンク」** を押すと、その名前のメモが同時にできます。

できたリンクは青い文字になります。クリックするとそのメモに移動します。

### Webサイトのリンクを貼る

同じ **「🔗 リンク」** の画面の下半分を使います。

![リンクの画面](docs/images/screen-link.png)

「表示する文字」と「リンク先URL」を入れて、貼り方を選びます。

| ボタン | どうなるか |
| --- | --- |
| 🔗 文字にリンク | 文字が青くなり、クリックするとブラウザで開きます |
| 🃏 カード | サイトのタイトル・説明・画像を自動で取ってきて、カードの形で貼ります |
| 📺 埋め込み | ページや動画をメモの中に表示します。YouTubeなどはそのまま再生できます |

**貼ったあとで直したいとき**は、そのリンクを **Ctrl を押しながらクリック** してください。
文字やリンク先を変えたり、リンクだけ外したりできます。

### 目次をつける

長いメモには目次をつけられます。

1. 文章を **「大見出し」** と **「小見出し」** で区切ります
2. 目次を置きたい場所にカーソルを合わせ、上の **「📑 目次」** を押します

見出しから自動で作られ、あとから見出しを増やしたり書き直したりしても自動でついてきます。
項目をクリックすると、その場所まで移動します。

### 画像を入れる

次のどの方法でも入ります。

- 上の **「🖼 画像」** を押してファイルを選ぶ
- 画像をコピーして、本文で **Ctrl + V**（スクリーンショットもそのまま貼れます）
- 画像ファイルを本文へドラッグして落とす

### ページの一番上に大きな画像を置く

タイトルの上にある **「🖼 トップ画像を追加」** を押して画像を選びます。
置いたあとは、画像の上にマウスを乗せると右下に
「画像を変更」「削除」のボタンが出ます。

### つながりを図で見る

左上の **「🗺 関連マップ」** を押すと、メモ同士のつながりが図で表示されます。

![関連マップ](docs/images/screen-map.png)

- **丸** がひとつのメモです。クリックするとそのメモが開きます
- **矢印** がリンクの向きです
- 丸が **大きいほど** たくさんつながっています
- **灰色の丸** は、まだどこともつながっていないメモです

丸はドラッグで動かせます。マウスのホイールで拡大・縮小、
何もない場所をドラッグすると全体を動かせます。

### 探す

左上の検索欄に文字を入れると、タイトルと本文の両方から探します。

### 保存

別のメモに移るときは自動で保存されます。
すぐ保存したいときは **「💾 保存」** ボタンか **Ctrl + S** です。

## 更新について

**新しいバージョンが出ると、アプリが自分で見つけて用意します。**
準備ができると画面の右下に案内が出るので、
**「再起動して更新」** を押すだけで新しくなります。
セットアップ画面などは出ず、そのまま新しいバージョンで起動します。

すぐに押さなくても大丈夫です。次にアプリを閉じたときに自動で新しくなります。
書きかけのメモがあるのに勝手に再起動することはありません。

更新したあと最初にアプリを開くと、**何が変わったのかをお知らせします**。
しばらく更新していなかった場合は、その間の変更を古い順に順番にお伝えします。

今のバージョンは、**画面左下**に表示されています。
その隣の **「更新を確認」** を押せば、その場で確認することもできます。

## メモはどこに保存される?

あなたのパソコンの中だけに保存されます。どこかに送信されることはありません。

場所は次のとおりです。エクスプローラーのアドレス欄に貼り付けると開けます。

```
%APPDATA%\memo-wiki\data
```

この `data` フォルダをコピーしておけば、それがそのままバックアップになります。
別のパソコンで使うときは、同じ場所にコピーすれば、メモをそのまま引き継げます。

**アプリを更新してもメモは消えません。** アンインストールしても残ります。
さらに、更新したときには念のため自動でバックアップが作られます
（`%APPDATA%\memo-wiki\backups` の中に、最新5回分）。

## 困ったときは

**Q. 起動しようとしたら青い警告画面が出ました**
「詳細情報」→「実行」を押してください。上の[インストール](#インストール)の注意書きに詳しく書いてあります。

**Q. 貼ったリンクの文字を書き直したい**
そのリンクを **Ctrl を押しながらクリック** すると、編集する画面が出ます。
ふつうにクリックするとリンク先が開いてしまうので、Ctrl が必要です。

**Q. YouTubeの動画が「動画プレーヤーの設定エラー」になります**
まず、動画ページのURLではなく **「共有 → 埋め込む」** で出てくる `<iframe …>` のコードを
コピーし、リンクの画面の **「リンク先URL」** 欄にそのまま貼り付けてみてください。
配信元が用意したURLをそのまま使うため、再生できる可能性が高くなります。

それでも表示されない場合があります。YouTubeは「どのサイトから埋め込まれたか」で
再生の可否を判断しており、パソコンの中で動くアプリはその条件を満たせないためです。
そのときは埋め込みの下にある **「ブラウザで開く」** から視聴してください。
動画以外のページを載せたいだけなら、「🃏 カード」で貼るのも見やすくおすすめです。

**Q. 埋め込んだWebページが真っ白のまま表示されません**
そのサイトが「他のアプリの中に表示されること」を禁止している場合があります。
この場合は表示できないので、代わりに「🃏 カード」で貼るのがおすすめです。

**Q. Webページからコピーしたら、色やレイアウトが変わってしまいました**
安全のために、外から持ち込んだ見た目の指定（色・文字の大きさなど）は取り除いています。
見出し・箇条書き・表・リンク・画像といった中身は残るようになっています。

**Q. 間違えてメモを消してしまいました**
`%APPDATA%\memo-wiki\backups` の中に、更新時点のバックアップが残っている場合があります。
中のファイルを `data` フォルダに戻すと復元できます。

**Q. トップ画像を消したのに、ファイルは残っていますか?**
残っています。あとから戻せるように、わざと消さないようにしています。

## 安全性とプライバシーについて

このアプリが何をしていて、何をしていないのかは
**[SECURITY.md](SECURITY.md)** にまとめています。

短くまとめると、次のとおりです。

- メモの内容は**あなたのパソコンの中だけ**に保存され、どこにも送信されません
- インターネットに接続するのは、次の3つのときだけです
  - リンクをカードで貼るとき（そのサイトの見出しを取りに行きます）
  - ページを埋め込んで表示するとき
  - 新しいバージョンが出ていないか確認するとき
- 正しい入手先は **このページの Releases だけ** です。他の場所で配られているものは使わないでください
