      Memo Wiki の使い方

      Wikipedia のように、メモ同士をリンクでつなげられるメモ帳です。
      覚える記号や書き方はありません。すべてボタンを押すだけでできます。

      メモを書く

      左上の 「+ 新規ページ」 で新しいメモを作ります。 上の欄にタイトル、その下に本文を書きます。 タイトルの下の細い欄に一行の説明（サブタイトル）を書いておくと、 左の一覧に表示されて見分けやすくなります。

      メモ同士をつなぐ

      1. つなげたい文字をドラッグして選びます
      2. 上の 「🔗 リンク」 を押します
      3. 出てきた一覧から、つなげたいメモをクリックします

      まだ無いメモにつなぎたいときは、 「「〇〇」で新しいページを作ってリンク」 を押すと、その名前のメモが同時にできます。 できたリンクをクリックすると、そのメモに移動します。

      Webサイトのリンクを貼る

      同じ「🔗 リンク」の画面の下半分で、「表示する文字」と「リンク先URL」を入れて貼り方を選びます。

      🔗 文字にリンク文字が青くなり、クリックするとブラウザで開きます
      🃏 カードサイトのタイトル・説明・画像を自動で取ってきて、カードの形で貼ります
      📺 動画・埋め込み動画のURLなら「動画カード」に、それ以外のページはメモの中に表示します

      動画を貼る

      YouTubeなどの動画URLを「リンク先URL」に入れて 「📺 動画・埋め込み」 を押すと、 サムネイルと ▶ が付いた 動画カード になります。 クリックすると、その動画がブラウザで開いて再生されます。

      動画をメモの中で直接再生することはできません。 YouTubeは「どのサイトから埋め込まれたか」で再生の可否を決めており、 パソコンの中で動くアプリにはその条件を満たす手段が無いためです (「動画プレーヤーの設定エラー(エラー153)」の正体がこれです)。 そのため、確実に見られる動画カードの形にしています。 サムネイルはメモと一緒に保存されるので、あとから開いても通信は発生しません。

      貼ったあとで直したいときは、Ctrl を押しながらクリック してください。

      文字のリンク表示する文字とリンク先を変えられます。「リンクを解除」で文字だけ残せます
      カード・動画・埋め込みリンク先を差し替えられます。「削除」を押すと、そのかたまりごと消せます

      目次をつける

      長いメモには目次をつけられます。文章を 「大見出し」 と 「小見出し」 で 区切ってから、目次を置きたい場所で 「📑 目次」 を押してください。 見出しから自動で作られ、あとで見出しを増やしたり書き直したりしても 自動でついてきます。項目をクリックすると、その場所まで移動します。

      画像を入れる

      • 上の 「🖼 画像」 を押してファイルを選ぶ
      • 画像をコピーして本文で Ctrl + V（スクリーンショットもそのまま貼れます）
      • 画像ファイルを本文へドラッグして落とす

      ページの一番上に大きな画像を置く

      タイトルの上の 「🖼 トップ画像を追加」 から選びます。 置いたあとは画像の上にマウスを乗せると、右下に「画像を変更」「削除」が出ます。

      フォルダに分ける

      一覧の上の 「+ フォルダ」 でフォルダを作れます。フォルダの中にフォルダも作れます。 ページやフォルダは、フォルダの見出しへドラッグすると移せます。 タイトルの下の「フォルダ」欄から選んで移すこともできます。

      • フォルダの見出しをクリックすると、そのフォルダを選びます。ダブルクリックで開閉します
      • 「+ 新規ページ」「+ フォルダ」は、選んでいるフォルダの中に作ります
      • 見出しにマウスを乗せると「名前」「×」が出ます。フォルダを消しても、中のページは消えずにひとつ上へ移ります

      ごみ箱

      「🗑 削除」 を押したページは、いったんごみ箱に入ります。 一覧の下の 「ごみ箱」 から、元に戻したり完全に削除したりできます。 ごみ箱に入れて30日たったページは、自動で完全に削除されます。

      つながりを図で見る

      左上の 「🗺 関連マップ」 を押すと、メモ同士のつながりが図で表示されます。

      • 丸 がひとつのメモです。クリックするとそのメモが開きます
      • 矢印 がリンクの向きです
      • 丸が大きいほどたくさんつながっています
      • 灰色の丸は、まだどこともつながっていないメモです

      丸はドラッグで動かせます。ホイールで拡大・縮小、何もない場所をドラッグすると全体が動きます。

      探す・保存する

      左上の検索欄に文字を入れると、タイトルと本文の両方から探します。
      保存は別のメモに移るときに自動で行われます。すぐ保存したいときは 「💾 保存」 か Ctrl + S です。

      キーボード操作

      Ctrl + S保存する
      Ctrl + Kリンクの画面を開く
      Ctrl + V貼り付ける（画像もそのまま入ります）
      Ctrl + クリック貼ってあるリンク・カード・埋め込みを編集する

      メモはどこに保存される?

      あなたのパソコンの中だけに保存され、どこにも送信されません。 場所はエクスプローラーのアドレス欄に %APPDATA%\memo-wiki\data と入れると開けます。 このフォルダをコピーすれば、それがそのままバックアップになります。

      書き出す・画像を整理する

      画面左下の 「データ」 ボタンから、次の2つができます。

      📤 メモを書き出すすべてのメモを、ブラウザで読める形でフォルダに書き出します。アプリに戻すための元データも一緒に入ります
      🧹 画像を整理するどのメモからも使われていない画像を探して、ごみ箱へ移します。間違えたときはごみ箱から元に戻せます

      更新について

      新しいバージョンが出ると、アプリが自分で見つけて用意します。 準備ができると右下に案内が出るので 「再起動して更新」 を押すだけです。 押さなくても、次にアプリを閉じたときに自動で新しくなります。

      データの管理

      メモを書き出す

      すべてのメモを、ブラウザで読める形でフォルダに書き出します。 アプリに戻すための元データも一緒に入ります。

      使っていない画像を整理する

      どのメモからも使われていない画像(外したトップ画像や、消したカードのサムネイルなど)を探して、 ごみ箱へ移します。ごみ箱から元に戻せます。
